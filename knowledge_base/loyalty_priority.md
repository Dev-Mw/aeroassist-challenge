# Prioridad y categoría de fidelidad

> Regla ficticia para el challenge.

La categoría de fidelidad puede usarse para ordenar una cola de atención, pero no cambia los requisitos de confirmación, seguridad ni disponibilidad. Nunca se deben inventar cupos preferentes.

Una persona `GOLD` o `PLATINUM` puede ser identificada como prioritaria para escalamiento humano. El dato se obtiene únicamente desde el contexto de reserva.
